# UK Job Market Data Engineering Platform

## Project Overview

An end-to-end data engineering platform designed to ingest,
process, store and analyse UK job-market data.

## Data Sources

- Adzuna API
- Reed API

## Technology Stack

- Python
- REST APIs
- AWS S3
- Apache Kafka
- Apache Spark
- PostgreSQL
- dbt
- Apache Airflow
- Amazon Athena
